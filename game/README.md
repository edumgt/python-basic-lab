# pygame3

`pygame3`는 **Python + Pygame**으로 만든 한국 장기(將棋) 게임 예제 프로젝트입니다.

## 프로젝트 개요

이 프로젝트는 9x10 장기판을 기반으로, 초(紅)와 한(藍)이 번갈아 두는 기본 플레이를 제공합니다.
주요 목적은 장기 규칙을 코드로 표현하고, Pygame을 이용해 간단한 GUI 보드게임을 구현하는 것입니다.

## 구현된 기능

- 9 x 10 장기판 렌더링
- 초/한 기본 기물 배치
- 기물 선택 및 이동 가능한 위치 표시
- 턴 기반 진행(초 선)
- 주요 기물 이동 규칙 구현
  - 차(車): 직선 무제한 이동
  - 포(包): 스크린 1개를 넘어 상대 기물만 잡기
  - 마(馬): 발 막힘 반영
  - 상(象): 대각 2칸(간단화 버전)
  - 사(士), 장/수(將/帥): 궁 내부 1칸 이동
  - 졸/병(卒/兵): 전/좌/우 이동 + 강 건넌 뒤 후진
- 체크(장군) 판정
- 체크메이트 판정
- 장수 마주보기(왕끼리 같은 줄에서 사이가 비면 체크 처리)

## 실행 방법

### 1) 의존성 설치

```bash
pip install pygame
```

### 2) 게임 실행

```bash
python jang.py
```

## 파일 구조

- `jang.py`: 게임 로직, 규칙 판정, 렌더링, 입력 처리 전체를 포함한 메인 파일

## 참고 사항

- 일부 규칙은 학습/데모 목적의 **간단화 버전**으로 구현되어 있습니다.
- 특히 상(象) 이동은 실제 장기 세부 규칙과 차이가 있을 수 있습니다.
- 실행 환경에 따라 한글 폰트(`malgungothic`)가 없으면 기본 폰트로 대체됩니다.
