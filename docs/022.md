# 🐍 특수 메서드 (`__str__`, `__repr__`)와 데이터 클래스

객체 표현 개선과 보일러플레이트 감소를 위한 핵심 패턴을 정리한 문서입니다.

---

## 1. 특수 메서드란?

`__이름__` 형태 메서드로 객체의 기본 동작을 커스터마이징합니다.

```python
class Book:
    def __init__(self, title):
        self.title = title

    def __str__(self):
        return f"Book: {self.title}"

    def __repr__(self):
        return f"Book(title={self.title!r})"
```

---

## 2. `dataclass` 사용

반복되는 `__init__`, `__repr__`, 비교 메서드를 자동 생성할 수 있습니다.

```python
from dataclasses import dataclass

@dataclass
class Point:
    x: int
    y: int
```

---

## 3. 언제 쓰면 좋은가?

- 값 객체(Value Object) 모델링
- 설정/DTO 구조 표현
- 테스트에서 비교 가능한 단순 객체 생성

---

## 4. 요약

- 특수 메서드는 객체 사용성을 높입니다.
- `dataclass`는 간결하고 실수 적은 OOP 모델 작성에 유리합니다.
