# 🐍 람다 표현식 (`lambda`) 가이드

익명 함수를 간단히 작성할 수 있는 `lambda` 표현식을 정리한 문서입니다.

---

## 1. 기본 문법

`lambda 매개변수: 반환식`

```python
add = lambda a, b: a + b
print(add(2, 3))  # 5
```

---

## 2. 자주 쓰는 상황

### 1) 정렬 키 함수

```python
students = [("Kim", 90), ("Lee", 75), ("Park", 88)]
sorted_students = sorted(students, key=lambda x: x[1], reverse=True)
print(sorted_students)
```

### 2) `map`, `filter`와 조합

```python
nums = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x * x, nums))
evens = list(filter(lambda x: x % 2 == 0, nums))
```

---

## 3. 주의할 점

- `lambda`는 **한 줄 표현식**만 가능하며, 복잡한 로직에는 부적합합니다.
- 재사용성/가독성이 중요하면 `def` 함수를 사용하는 것이 좋습니다.

---

## 4. 요약

- 짧은 함수는 `lambda`로 간결하게 작성 가능
- 정렬, 변환, 필터링에서 특히 자주 사용
- 복잡해지면 일반 함수(`def`)로 전환하는 것이 유지보수에 유리
