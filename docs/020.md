# 🐍 캡슐화와 `property`

객체 내부 상태를 안전하게 다루는 캡슐화 기법을 정리한 문서입니다.

---

## 1. 캡슐화란?

데이터와 로직을 묶고, 내부 구현을 외부에서 직접 건드리지 못하게 제어하는 개념입니다.

파이썬은 강제 접근제어자(`private`) 대신 관례를 사용합니다.

- `_name`: 내부용(약한 비공개 관례)
- `__name`: name mangling 적용(강한 보호 효과)

---

## 2. `property`로 안전한 접근 제공

```python
class Account:
    def __init__(self, balance=0):
        self._balance = balance

    @property
    def balance(self):
        return self._balance

    @balance.setter
    def balance(self, value):
        if value < 0:
            raise ValueError("잔액은 음수가 될 수 없습니다.")
        self._balance = value
```

---

## 3. 장점

1. 기존 `obj.value` 접근 문법을 유지한 채 검증 로직 추가 가능
2. 내부 구현 변경 시 외부 인터페이스를 안정적으로 유지 가능

---

## 4. 요약

- 캡슐화는 객체 안정성과 유지보수성을 높입니다.
- 파이썬에서는 `property`가 핵심 도구입니다.
