# 🐍 다형성, 덕 타이핑, 추상 클래스

같은 인터페이스로 다양한 객체를 다루는 다형성 개념을 정리한 문서입니다.

---

## 1. 다형성(Polymorphism)

동일한 메서드 호출이 객체 타입에 따라 다르게 동작하는 특성입니다.

```python
class Cat:
    def speak(self):
        return "야옹"

class Dog:
    def speak(self):
        return "멍멍"

for animal in [Cat(), Dog()]:
    print(animal.speak())
```

---

## 2. 덕 타이핑(Duck Typing)

파이썬은 "타입"보다 "행동(메서드 보유 여부)"을 중시합니다.

> "오리처럼 걷고 오리처럼 울면 오리다."

---

## 3. 추상 클래스(ABC)

명확한 인터페이스 강제가 필요하면 `abc` 모듈을 사용합니다.

```python
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        ...
```

---

## 4. 요약

- 파이썬의 다형성은 덕 타이핑 기반으로 매우 유연합니다.
- 팀 규칙/대규모 설계에서는 ABC로 계약(인터페이스)을 명시하면 좋습니다.
