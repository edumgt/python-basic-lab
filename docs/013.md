# 🐍 예외 처리 (Exception Handling) 가이드

안정적인 프로그램을 위한 예외 처리 기초와 실전 포인트를 정리한 문서입니다.

---

## 1. 기본 구조

```python
try:
    value = int("10")
except ValueError:
    print("숫자 변환 실패")
else:
    print("성공:", value)
finally:
    print("항상 실행")
```

---

## 2. 여러 예외 처리

```python
try:
    result = 10 / int(input_value)
except (ValueError, ZeroDivisionError) as e:
    print(f"오류 발생: {e}")
```

---

## 3. 예외 다시 발생시키기

```python
def read_config(path):
    try:
        with open(path, "r", encoding="utf-8") as f:
            return f.read()
    except OSError as e:
        raise RuntimeError("설정 파일 로드 실패") from e
```

---

## 4. 사용자 정의 예외

```python
class InvalidAgeError(ValueError):
    pass
```

---

## 5. 실무 팁

- 광범위한 `except Exception:` 남용을 피하고, 구체적 예외를 잡는 것이 좋습니다.
- 예외를 숨기기보다 맥락을 보강해 상위로 전달하는 것이 디버깅에 유리합니다.
