# 🐍 Python 내장 함수 및 유용한 기능 정리 (20+)

---

### 1. `zip()`

여러 iterable을 묶어서 튜플 형태로 반환합니다.

```python
names = ["Tom", "Jane", "Mike"]
scores = [90, 85, 77]
for name, score in zip(names, scores):
    print(name, score)
```

---

### 2. `enumerate()`

iterable에 인덱스를 함께 반환합니다.

```python
for idx, val in enumerate(["a", "b", "c"]):
    print(idx, val)
```

---

### 3. `map()`

함수와 iterable을 매핑하여 새로운 iterator를 생성합니다.

```python
nums = [1, 2, 3]
squared = list(map(lambda x: x**2, nums))
```

---

### 4. `filter()`

조건 함수로 걸러낸 요소만 반환합니다.

```python
nums = [1, 2, 3, 4, 5]
evens = list(filter(lambda x: x % 2 == 0, nums))
```

---

### 5. `lambda`

익명 함수를 정의할 때 사용합니다.

```python
add = lambda a, b: a + b
print(add(3, 5))  # 8
```

---

### 6. `sorted()`

정렬된 리스트를 반환합니다. (원본은 유지)

```python
nums = [3, 1, 4]
print(sorted(nums))  # [1, 3, 4]
```

---

### 7. `reversed()`

역순 iterator를 반환합니다.

```python
for x in reversed([1, 2, 3]):
    print(x)
```

---

### 8. `range()`

숫자 시퀀스를 생성합니다.

```python
for i in range(3):
    print(i)  # 0, 1, 2
```

---

### 9. `len()`

객체의 길이를 반환합니다.

```python
print(len("Python"))  # 6
```

---

### 10. `sum()`

합계를 반환합니다.

```python
print(sum([1, 2, 3]))  # 6
```

---

### 11. `min()` / `max()`

최소값 / 최대값을 반환합니다.

```python
print(min([3, 1, 4]))  # 1
print(max([3, 1, 4]))  # 4
```

---

### 12. `any()` / `all()`

- `any()`: 하나라도 참이면 `True`
- `all()`: 모두 참이면 `True`

```python
print(any([0, 1, 0]))  # True
print(all([1, 2, 3]))  # True
```

---

### 13. `dict()`

딕셔너리를 생성합니다.

```python
d = dict(a=1, b=2)
print(d)  # {'a': 1, 'b': 2}
```

---

### 14. `set()`

집합을 생성합니다.

```python
s = set([1, 2, 2, 3])
print(s)  # {1, 2, 3}
```

---

### 15. `list()` / `tuple()`

리스트 / 튜플을 생성합니다.

```python
print(list("abc"))   # ['a', 'b', 'c']
print(tuple("abc"))  # ('a', 'b', 'c')
```

---

### 16. `type()`

객체 타입을 확인합니다.

```python
print(type(3))  # <class 'int'>
```

---

### 17. `isinstance()`

특정 클래스/타입 여부를 확인합니다.

```python
print(isinstance(3, int))  # True
```

---

### 18. `dir()`

객체의 속성과 메서드를 확인합니다.

```python
print(dir([]))  # 리스트 관련 메서드 목록
```

---

### 19. `help()`

내장 도움말 시스템을 호출합니다.

```python
help(len)
```

---

### 20. `divmod()`

몫과 나머지를 동시에 반환합니다.

```python
print(divmod(7, 3))  # (2, 1)
```
