# 🐍 제너레이터 (Generator) 가이드

`yield`를 사용해 이터레이터를 간결하게 만드는 제너레이터를 정리한 문서입니다.

---

## 1. 제너레이터 함수

```python
def count_up(n):
    i = 1
    while i <= n:
        yield i
        i += 1

for num in count_up(3):
    print(num)  # 1, 2, 3
```

---

## 2. 제너레이터 표현식

리스트 컴프리헨션과 유사하지만, 즉시 전체를 만들지 않고 지연 평가합니다.

```python
squares = (x * x for x in range(1, 6))
print(next(squares))  # 1
print(next(squares))  # 4
```

---

## 3. 제너레이터의 장점

1. **메모리 효율**: 큰 데이터 처리에 유리
2. **지연 실행**: 필요할 때만 계산
3. **파이프라인 구성**: 데이터 처리 단계를 함수로 연결하기 좋음

---

## 4. 이터레이터와의 관계

- 모든 제너레이터는 이터레이터입니다.
- `yield`를 쓰면 `__iter__`, `__next__`를 직접 구현하지 않아도 됩니다.
