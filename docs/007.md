# 🐍 `*args`, `**kwargs` 가이드

함수 인자를 유연하게 다루기 위한 `*args`, `**kwargs`를 정리한 문서입니다.

---

## 1. `*args`란?

`*args`는 **위치 인자(positional arguments)를 개수 제한 없이** 받을 때 사용합니다.  
함수 내부에서는 `tuple`로 다뤄집니다.

```python
def add_all(*args):
    return sum(args)

print(add_all(1, 2, 3))       # 6
print(add_all(10, 20, 30, 40)) # 100
```

---

## 2. `**kwargs`란?

`**kwargs`는 **키워드 인자(keyword arguments)를 개수 제한 없이** 받을 때 사용합니다.  
함수 내부에서는 `dict`로 다뤄집니다.

```python
def print_profile(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

print_profile(name="Kim", age=20, major="CS")
```

---

## 3. 함께 쓰기

일반적으로 함수 시그니처 순서는 다음과 같습니다.

1. 일반 위치 인자
2. `*args`
3. 키워드 전용 인자
4. `**kwargs`

```python
def func(a, b, *args, option=True, **kwargs):
    print(a, b, args, option, kwargs)
```

---

## 4. 언패킹(Unpacking)

리스트/튜플/딕셔너리를 함수 인자로 펼칠 때도 `*`, `**`를 사용합니다.

```python
nums = [1, 2, 3]
config = {"sep": " - ", "end": "\n"}

print(*nums)              # 1 2 3
print("A", "B", **config) # A - B
```

---

## 5. 요약

- `*args`: 가변 위치 인자(튜플)
- `**kwargs`: 가변 키워드 인자(딕셔너리)
- API 유연성을 높일 때 매우 유용하지만, 남용하면 가독성이 떨어질 수 있습니다.
