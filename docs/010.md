# 🐍 클로저 (Closure) 가이드

중첩 함수가 바깥 스코프의 값을 기억하는 클로저를 정리한 문서입니다.

---

## 1. 클로저란?

내부 함수가 **외부 함수의 지역 변수를 참조한 상태로 반환**될 때 만들어지는 함수 객체입니다.

```python
def make_multiplier(n):
    def multiply(x):
        return x * n
    return multiply

times3 = make_multiplier(3)
print(times3(10))  # 30
```

---

## 2. 핵심 포인트

- 외부 함수가 종료되어도 내부 함수는 참조한 값을 기억합니다.
- 함수형 프로그래밍 스타일에서 상태를 은닉할 때 유용합니다.

---

## 3. `nonlocal` 사용

클로저 내부에서 외부 지역 변수 값을 변경하려면 `nonlocal`이 필요합니다.

```python
def counter():
    count = 0

    def inc():
        nonlocal count
        count += 1
        return count

    return inc
```

---

## 4. 요약

- 클로저는 "함수 + 기억된 상태"입니다.
- 간단한 상태 저장 로직을 클래스 없이 구현할 수 있습니다.
