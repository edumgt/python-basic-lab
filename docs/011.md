# 🐍 데코레이터 (Decorator) 가이드

함수/메서드에 기능을 덧붙이는 데코레이터를 정리한 문서입니다.

---

## 1. 데코레이터란?

기존 함수를 수정하지 않고 **전/후처리 로직을 래핑**하는 문법입니다.

```python
def my_decorator(func):
    def wrapper(*args, **kwargs):
        print("before")
        result = func(*args, **kwargs)
        print("after")
        return result
    return wrapper

@my_decorator
def hello():
    print("hello")
```

---

## 2. 인자를 받는 데코레이터

```python
def repeat(n):
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(n):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hi():
    print("hi")
```

---

## 3. `functools.wraps` 권장

래핑 시 원본 함수 메타데이터를 보존하려면 `@wraps`를 사용합니다.

```python
from functools import wraps
```
