# 🐍 `@classmethod`와 `@staticmethod`

클래스 수준 동작과 정적 유틸리티 메서드의 차이를 정리한 문서입니다.

---

## 1. 인스턴스 메서드와 비교

- 인스턴스 메서드: 첫 인자 `self`
- 클래스 메서드: 첫 인자 `cls`
- 정적 메서드: 자동 전달 인자 없음

---

## 2. `@classmethod`

클래스 자체를 다루는 팩토리 메서드 구현에 자주 사용합니다.

```python
class User:
    def __init__(self, name):
        self.name = name

    @classmethod
    def from_email(cls, email):
        name = email.split("@")[0]
        return cls(name)
```

---

## 3. `@staticmethod`

클래스/인스턴스 상태를 쓰지 않는 유틸리티 함수를 클래스 내부에 둘 때 사용합니다.

```python
class MathUtil:
    @staticmethod
    def is_even(n):
        return n % 2 == 0
```

---

## 4. 요약

- 클래스 상태를 다루면 `@classmethod`
- 상태와 무관한 보조 함수면 `@staticmethod`
