# 🐍 객체 지향 프로그래밍 (OOP) 기초

파이썬 객체 지향의 핵심 개념인 클래스와 객체를 정리한 문서입니다.

---

## 1. 객체 지향이란?

객체 지향 프로그래밍(Object-Oriented Programming)은 데이터(속성)와 동작(메서드)을 하나로 묶어 모델링하는 방식입니다.

- **클래스(Class)**: 객체를 만들기 위한 설계도
- **객체(Object, 인스턴스)**: 클래스로부터 생성된 실제 값

---

## 2. 첫 클래스 만들기

```python
class Dog:
    def bark(self):
        print("멍멍")

my_dog = Dog()
my_dog.bark()
```

---

## 3. `self`의 의미

인스턴스 메서드의 첫 번째 인자인 `self`는 **메서드를 호출한 객체 자신**을 가리킵니다.

```python
class User:
    def hello(self):
        print("hello from", self)
```

---

## 4. 요약

- OOP의 출발점은 클래스/객체 이해입니다.
- 이후 생성자, 상속, 다형성, 캡슐화로 확장됩니다.
