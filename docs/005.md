# 🐍 파이썬 리스트 컴프리헨션 (List Comprehension) & 딕셔너리 컴프리헨션 가이드

기존 데이터를 기반으로 새로운 리스트나 딕셔너리를 **간결하고 직관적으로 생성**할 수 있는 파이썬의 강력한 문법입니다.

---

## 1. 기본 개념
* **리스트 컴프리헨션 문법:**  
  `[표현식 for 항목 in 반복가능객체 if 조건]`
* **딕셔너리 컴프리헨션 문법:**  
  `{키: 값 for 항목 in 반복가능객체 if 조건}`
* **장점:** 일반적인 `for` 루프보다 코드가 짧고 가독성이 좋으며, 실행 속도도 빠릅니다.

---

## 2. 주요 예시 모음

```python
# 📍 1. 기본 제곱 리스트 생성
squares = [i**2 for i in range(1, 6)]
print(squares)
# 결과: [1, 4, 9, 16, 25]

# 📍 2. 조건문 포함 (짝수만 제곱)
even_squares = [i**2 for i in range(1, 11) if i % 2 == 0]
print(even_squares)
# 결과: [4, 16, 36, 64, 100]

# 📍 3. 중첩 루프 활용 (구구단)
multiplication_table = [i*j for i in range(1, 4) for j in range(1, 4)]
print(multiplication_table)
# 결과: [1, 2, 3, 2, 4, 6, 3, 6, 9]

# 📍 4. 문자열 처리 (대문자 변환)
words = ["python", "list", "comprehension"]
upper_words = [w.upper() for w in words]
print(upper_words)
# 결과: ['PYTHON', 'LIST', 'COMPREHENSION']

# 📍 5. 딕셔너리 컴프리헨션 (숫자와 제곱 매핑)
square_dict = {i: i**2 for i in range(1, 6)}
print(square_dict)
# 결과: {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# 📍 6. 조건문 포함 딕셔너리 (짝수만 매핑)
even_square_dict = {i: i**2 for i in range(1, 11) if i % 2 == 0}
print(even_square_dict)
# 결과: {2: 4, 4: 16, 6: 36, 8: 64, 10: 100}
