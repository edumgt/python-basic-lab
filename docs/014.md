# 🐍 이터레이터 (Iterator) 가이드

반복 가능한 객체를 한 요소씩 순회하는 이터레이터 개념을 정리한 문서입니다.

---

## 1. 반복 가능 객체 vs 이터레이터

- **Iterable**: `for`로 순회 가능한 객체 (`list`, `tuple`, `str` 등)
- **Iterator**: `next()`로 다음 값을 하나씩 꺼낼 수 있는 객체

```python
nums = [1, 2, 3]
it = iter(nums)
print(next(it))  # 1
print(next(it))  # 2
```

---

## 2. 이터레이터 프로토콜

이터레이터 객체는 보통 다음을 구현합니다.

1. `__iter__(self)` -> 자기 자신 반환
2. `__next__(self)` -> 다음 값 반환, 종료 시 `StopIteration` 발생

```python
class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value
```

---

## 3. 요약

- 이터레이터는 지연(lazy) 방식으로 값을 생산해 메모리 효율에 유리합니다.
- `for` 문 내부는 결국 `iter()` + `next()` 호출 흐름으로 동작합니다.
