# 🐼 pandas 기초와 Series 핵심 사용법

`pandas`는 표 형태 데이터를 다루는 대표 파이썬 라이브러리입니다.  
이 문서는 `pandas`의 기본 개념을 짚고, 특히 1차원 자료구조인 **Series** 사용법을 보완해 정리합니다.

---

## 1. pandas란?

`pandas`는 데이터 정제, 집계, 분석에 자주 쓰입니다.

- 엑셀/CSV처럼 행·열 형태 데이터를 다루기 쉽습니다.
- 결측치(`NaN`) 처리, 그룹 집계, 정렬/필터 기능이 강력합니다.
- 핵심 자료구조는 `Series`와 `DataFrame`입니다.

```python
import pandas as pd
```

---

## 2. Series란?

`Series`는 **인덱스(index) + 값(value)**으로 구성된 1차원 배열입니다.

- 리스트와 비슷하지만 인덱스 라벨을 가질 수 있습니다.
- 숫자, 문자열, 불리언 등 다양한 타입을 저장할 수 있습니다.
- `DataFrame`의 한 열(column)은 사실상 `Series`입니다.

```python
import pandas as pd

s = pd.Series([10, 20, 30], index=["a", "b", "c"])
print(s)
```

---

## 3. Series 생성 방법

### 3-1. 리스트로 생성

```python
s = pd.Series([95, 88, 76])
```

### 3-2. 인덱스 지정

```python
s = pd.Series([95, 88, 76], index=["국어", "영어", "수학"])
```

### 3-3. 딕셔너리로 생성

```python
s = pd.Series({"kim": 85, "lee": 92, "park": 78})
```

---

## 4. 자주 쓰는 Series 속성/메서드

| 항목 | 설명 |
|---|---|
| `s.index` | 인덱스 목록 |
| `s.values` | 값 배열 |
| `s.dtype` | 데이터 타입 |
| `s.shape` | 크기(튜플) |
| `s.head(n)` | 앞 n개 확인 |
| `s.tail(n)` | 뒤 n개 확인 |
| `s.describe()` | 요약 통계 |
| `s.value_counts()` | 값별 빈도 |
| `s.unique()` | 중복 제거된 값 |

---

## 5. 인덱싱과 슬라이싱

### 5-1. 라벨 기반 접근

```python
print(s["영어"])
```

### 5-2. 위치 기반 접근(`iloc`)

```python
print(s.iloc[0])
```

### 5-3. 범위 슬라이싱

```python
print(s.iloc[0:2])
```

---

## 6. Series 연산

Series는 벡터 연산이 가능합니다.

```python
s = pd.Series([1, 2, 3, 4])
print(s + 10)       # 각 원소에 10 더하기
print(s * 2)        # 각 원소에 2 곱하기
print(s.mean())     # 평균
print(s.sum())      # 합계
```

조건 필터도 자주 사용합니다.

```python
print(s[s >= 3])    # 3 이상만 추출
```

---

## 7. 결측치(NaN) 처리

실무 데이터에는 비어 있는 값이 자주 있습니다.

```python
s = pd.Series([10, None, 30, None, 50])

print(s.isna())          # 결측치 여부
print(s.dropna())        # 결측치 제거
print(s.fillna(0))       # 결측치를 0으로 대체
print(s.fillna(s.mean()))# 평균으로 대체
```

---

## 8. map/apply로 값 변환

값 전처리에 유용한 기능입니다.

```python
s = pd.Series(["apple", "banana", "grape"])
print(s.map(len))  # 문자열 길이 변환
```

```python
s = pd.Series([1, 2, 3, 4, 5])
print(s.apply(lambda x: x ** 2))  # 제곱
```

---

## 9. Series와 DataFrame 관계

`Series` 여러 개가 모이면 `DataFrame`이 됩니다.

```python
df = pd.DataFrame({
    "name": ["kim", "lee", "park"],
    "score": [80, 90, 85],
})

score_series = df["score"]   # DataFrame의 한 열 -> Series
print(type(score_series))    # <class 'pandas.core.series.Series'>
```

---

## 10. 한눈에 요약

- `pandas`는 데이터 분석용 표준 라이브러리입니다.
- `Series`는 인덱스가 있는 1차원 데이터 구조입니다.
- `Series`는 생성, 인덱싱, 연산, 결측치 처리, 변환(`map/apply`)이 핵심입니다.
- 이후 `DataFrame` 학습으로 확장하면 실전 데이터 분석 흐름을 만들 수 있습니다.
