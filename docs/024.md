# 🧺 튜플(tuple), 딕셔너리(dict), 집합(set) 기초

파이썬에서 자주 사용하는 대표 컬렉션 자료형인 **튜플**, **딕셔너리**, **집합**의 핵심 개념을 한 번에 정리한 문서입니다.

---

## 1. 튜플(tuple)

튜플은 여러 값을 **순서 있게 저장**하는 자료형입니다.

- 소괄호 `()`를 사용합니다.
- 한 번 만들면 요소를 직접 변경할 수 없는 **불변(immutable)** 자료형입니다.
- 인덱싱과 슬라이싱이 가능합니다.

```python
point = (3, 5)
colors = ("red", "green", "blue")

print(point[0])      # 3
print(colors[1:])    # ('green', 'blue')
```

### 튜플을 사용하는 이유

- 좌표, RGB 값처럼 **변하지 않아야 하는 묶음 데이터**를 표현하기 좋습니다.
- 함수에서 여러 값을 반환할 때 자주 사용됩니다.

```python
def get_user():
    return ("alice", 20)

name, age = get_user()
print(name, age)
```

---

## 2. 딕셔너리(dict)

딕셔너리는 **키(key)와 값(value)** 을 쌍으로 저장하는 자료형입니다.

- 중괄호 `{}`를 사용합니다.
- 키를 이용해 원하는 값을 빠르게 찾을 수 있습니다.
- 키는 보통 문자열, 숫자, 튜플처럼 **변경 불가능한 값**이어야 합니다.

```python
student = {
    "name": "Kim",
    "grade": 1,
    "score": 95,
}

print(student["name"])      # Kim
print(student.get("score")) # 95
```

### 자주 쓰는 딕셔너리 동작

```python
student["grade"] = 2
student["school"] = "Python High"

print(student.keys())    # dict_keys(['name', 'grade', 'score', 'school'])
print(student.values())  # dict_values(['Kim', 2, 95, 'Python High'])
print(student.items())   # dict_items([('name', 'Kim'), ...])
```

### 딕셔너리를 사용하는 이유

- 학생 정보, 설정값, API 응답처럼 **이름이 있는 데이터**를 다루기 좋습니다.
- 리스트보다 의미가 명확해서 가독성이 좋습니다.

---

## 3. 집합(set)

집합은 **중복 없는 값들의 모음**을 저장하는 자료형입니다.

- 중괄호 `{}`를 사용하지만, `{"a": 1}` 같은 딕셔너리와는 다릅니다.
- 순서가 보장되지 않습니다.
- 중복 제거와 교집합/합집합 계산에 매우 유용합니다.

```python
numbers = {1, 2, 2, 3, 4}
print(numbers)  # {1, 2, 3, 4}
```

### 집합 연산 예시

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # 합집합: {1, 2, 3, 4, 5}
print(a & b)  # 교집합: {3}
print(a - b)  # 차집합: {1, 2}
```

### 집합을 사용하는 이유

- 리스트에서 **중복을 제거**할 때 편리합니다.
- 공통 데이터 찾기 같은 연산을 간단하게 처리할 수 있습니다.

```python
tags = ["python", "ai", "python", "fastapi"]
unique_tags = set(tags)
print(unique_tags)
```

## 4. 세 자료형 비교

| 자료형 | 문법 예시 | 순서 | 중복 허용 | 수정 가능 |
|---|---|---|---|---|
| 튜플 | `(1, 2, 3)` | O | O | X |
| 딕셔너리 | `{"a": 1, "b": 2}` | 키 기준 관리 | 키 중복 X | O |
| 집합 | `{1, 2, 3}` | X | X | O |

## 5. 언제 무엇을 쓰면 될까?

- **튜플**: 변경되면 안 되는 묶음 데이터
- **딕셔너리**: 이름표가 붙은 정보 저장
- **집합**: 중복 제거, 공통값/차이값 계산
