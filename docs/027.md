## 1. 거듭제곱(冪乘)과 지수(指數)

`a^n` 형태를 **거듭제곱**이라고 하고,  
여기서 `n`을 **지수**라고 합니다.

- 밑(base): `a`
- 지수(exponent): `n`
- 의미: `a`를 `n`번 곱함

예:

- `2^3 = 2 × 2 × 2 = 8`
- `10^2 = 100`

파이썬에서는 `**` 연산자를 사용합니다.

```python
print(2 ** 3)   # 8
print(10 ** 2)  # 100
```

---

## 2. 제곱근(平方根)

어떤 수를 제곱해서 원래 수가 되게 하는 값을 **제곱근**이라고 합니다.

- `x^2 = 9`를 만족하는 수는 `x = 3, -3`
- 보통 `√9`는 양의 값 `3`을 뜻합니다.

파이썬 실습:

```python
import math

print(math.sqrt(9))    # 3.0
print(16 ** 0.5)       # 4.0
```

---

## 3. 등식(等式), 미지수(未知數), 해(解)

- **등식**: `왼쪽 = 오른쪽`처럼 같음을 나타내는 식
- **미지수**: 값을 아직 모르는 문자(예: `x`, `y`)
- **해**: 등식을 참으로 만드는 미지수의 값

예: `x + 2 = 5`  
이 식을 참으로 만드는 값은 `x = 3`이므로 해는 3입니다.

---

## 4. 일차방정식(一次方程式)

미지수의 최고차수가 1인 방정식입니다.

일반형:

`ax + b = 0` (`a ≠ 0`)

해 공식:

`x = -b / a`

파이썬 함수로 만들기:

```python
def solve_linear(a: float, b: float) -> float:
    if a == 0:
        raise ValueError("a는 0이 될 수 없습니다.")
    return -b / a

print(solve_linear(2, -6))   # 3.0  -> 2x - 6 = 0
```

## 5. 연립일차방정식(聯立一次方程式)

미지수가 2개 이상이고, 방정식이 여러 개 묶인 형태입니다.

예:

```text
2x + y = 5
x - y = 1
```

두 식을 동시에 만족하는 `x`, `y`를 찾는 것이 목표입니다.

### 5-1. 대입/소거로 직접 풀기

두 번째 식에서 `x = y + 1`  
첫 번째 식에 대입:

`2(y + 1) + y = 5`  
`3y = 3` → `y = 1`  
`x = 2`

### 5-2. 파이썬으로 계산(직접 공식 사용)

```python
def solve_2x2(
    a: float, b: float, c: float,
    d: float, e: float, f: float,
) -> tuple[float, float]:
    """
    ax + by = c
    dx + ey = f
    """
    det = a * e - b * d
    if det == 0:
        raise ValueError("해가 없거나 무수히 많습니다.")
    x = (c * e - b * f) / det
    y = (a * f - c * d) / det
    return x, y

x, y = solve_2x2(2, 1, 5, 1, -1, 1)
print(x, y)  # 2.0 1.0
```

## 6. 행렬(行列)의 수학적 의미

행렬은 숫자를 직사각형 배열로 정리한 것입니다.

```text
[ 2  1 ]
[ 1 -1 ]
```

연립일차방정식을 행렬로 쓰면 계산 구조가 명확해집니다.

`A x = b`

- `A`: 계수 행렬
- `x`: 미지수 벡터
- `b`: 상수 벡터

위 예제를 행렬로 쓰면:

```text
[ 2  1 ] [x] = [5]
[ 1 -1 ] [y]   [1]
```

즉, 연립일차방정식은 **행렬 방정식**으로 표현할 수 있고,  
해를 구하는 과정은 선형대수 계산으로 연결됩니다.

---

## 7. 선형대수(Linear Algebra)란?

선형대수는 **벡터와 행렬을 사용해 여러 값을 동시에 다루는 수학**입니다.

- 벡터(vector): 여러 수를 한 줄로 담은 값(예: `[2, 3]`)
- 행렬(matrix): 벡터를 여러 줄로 확장한 값(예: `[[2, 1], [1, -1]]`)

특히 아래 문제를 풀 때 자주 사용됩니다.

- 연립일차방정식 해 구하기
- 데이터 분석/머신러닝의 수치 계산
- 2D/3D 좌표 변환(회전, 확대/축소, 이동)

---

## 8. 벡터(Vector) 기초

### 8-1. 벡터의 의미

벡터는 보통 두 가지로 이해합니다.

1. 여러 수를 묶은 데이터
2. 크기와 방향을 가진 양(물리/기하 관점)

예:

```text
v = [2, 3]
w = [1, -4]
```

### 8-2. 벡터의 핵심 연산

- 덧셈: `v + w = [3, -1]`
- 스칼라배: `2v = [4, 6]`
- 내적(dot product): `v·w = 2*1 + 3*(-4) = -10`

내적은 두 벡터가 얼마나 같은 방향인지(유사도) 판단할 때 자주 씁니다.

---

## 9. 행렬(Matrix) 기초

### 9-1. 행렬의 모양(shape)

아래 행렬 `A`는 **2행 2열(2x2)** 입니다.

```text
A = [ [2, 1],
      [1, -1] ]
```

### 9-2. 행렬 곱의 의미

행렬 곱은 단순한 칸별 곱셈이 아니라,  
**행(row)과 열(column)의 내적**으로 계산됩니다.

예:

```text
A = [ [1, 2],
      [3, 4] ]

B = [ [2, 0],
      [1, 2] ]

A @ B = [ [4, 4],
          [10, 8] ]
```

행렬 곱은 선형 변환을 합성하는 연산으로도 볼 수 있습니다.

## 10. 파이썬 실습: 리스트 기반 행렬 계산(기초)

외부 라이브러리 없이도 2×2는 직접 풀 수 있습니다.

```python
A = [[2, 1], [1, -1]]
b_vec = [5, 1]

def solve_by_matrix_2x2(A, constants):
    a11, a12 = A[0]
    a21, a22 = A[1]
    b1, b2 = constants
    det = a11 * a22 - a12 * a21
    if det == 0:
        raise ValueError("역행렬이 없어 해를 구할 수 없습니다.")
    x = (b1 * a22 - a12 * b2) / det
    y = (a11 * b2 - b1 * a21) / det
    return x, y

print(solve_by_matrix_2x2(A, b_vec))  # (2.0, 1.0)
```

## 11. NumPy 실습: 벡터·행렬 계산

실무/과학계산에서는 리스트보다 `NumPy`를 더 많이 사용합니다.

```python
import numpy as np

# 벡터
v = np.array([2, 3])
w = np.array([1, -4])

print(v + w)        # [ 3 -1]
print(2 * v)        # [4 6]
print(v @ w)        # -10 (내적)

# 행렬
A = np.array([[2, 1], [1, -1]])
B = np.array([[1, 2], [3, 4]])

print(A.shape)      # (2, 2)
print(A @ B)        # 행렬 곱

# 연립방정식 A x = b
b_vec = np.array([5, 1])
x = np.linalg.solve(A, b_vec)
print(x)            # [2. 1.]
```

### 11-1. NumPy에서 자주 보는 함수

- `np.array(...)`: 배열(벡터/행렬) 생성
- `.shape`: 배열 크기 확인
- `@`: 벡터 내적/행렬 곱
- `np.linalg.solve(A, b)`: `A x = b` 해 계산
- `np.linalg.inv(A)`: 역행렬(가능하면 `solve`를 우선 사용)

## 12. 학습 체크포인트

- `**`는 거듭제곱 연산자다.
- 제곱근은 `math.sqrt()` 또는 `x ** 0.5`로 계산할 수 있다.
- 일차방정식 `ax+b=0`의 해는 `-b/a`다.
- 연립일차방정식은 여러 식을 동시에 만족하는 값을 찾는다.
- 연립식은 `A x = b` 행렬 형태로 표현할 수 있다.
- 벡터는 덧셈/스칼라배/내적이 핵심 연산이다.
- 행렬 곱은 행과 열의 내적으로 계산한다.
- NumPy의 `np.linalg.solve`로 연립방정식을 안정적으로 풀 수 있다.

## 13. 한눈에 요약

- **거듭제곱**: 같은 수를 여러 번 곱하는 연산
- **지수**: 몇 번 곱하는지 나타내는 수
- **제곱근**: 제곱했을 때 원래 수가 되는 값
- **등식**: 두 식이 같음을 나타내는 식
- **미지수**: 아직 모르는 값(문자)
- **해**: 방정식을 참으로 만드는 값
- **연립일차방정식**: 여러 일차방정식을 동시에 만족하는 해를 찾는 문제
- **선형대수**: 벡터/행렬로 다변수 문제를 다루는 수학
- **벡터**: 여러 수를 담은 1차원 구조, 내적이 중요
- **행렬**: 연립방정식을 구조적으로 표현하고 계산하는 도구
- **NumPy**: 벡터/행렬 계산을 빠르고 간결하게 처리하는 파이썬 라이브러리
