## 1. 거듭제곱(冪乘)과 지수(指數)

`a^n` 형태를 **거듭제곱**이라고 하고,  
여기서 `n`을 **지수**라고 합니다.

- 밑(base): `a`
- 지수(exponent): `n`
- 의미: `a`를 `n`번 곱함

예:

- `2^3 = 2 × 2 × 2 = 8`
- `10^2 = 100`

파이썬에서는 `**` 연산자를 사용합니다.

```python
print(2 ** 3)   # 8
print(10 ** 2)  # 100
```

---

## 2. 제곱근(平方根)

어떤 수를 제곱해서 원래 수가 되게 하는 값을 **제곱근**이라고 합니다.

- `x^2 = 9`를 만족하는 수는 `x = 3, -3`
- 보통 `√9`는 양의 값 `3`을 뜻합니다.

파이썬 실습:

```python
import math

print(math.sqrt(9))    # 3.0
print(16 ** 0.5)       # 4.0
```

---

## 3. 등식(等式), 미지수(未知數), 해(解)

- **등식**: `왼쪽 = 오른쪽`처럼 같음을 나타내는 식
- **미지수**: 값을 아직 모르는 문자(예: `x`, `y`)
- **해**: 등식을 참으로 만드는 미지수의 값

예: `x + 2 = 5`  
이 식을 참으로 만드는 값은 `x = 3`이므로 해는 3입니다.

---

## 4. 일차방정식(一次方程式)

미지수의 최고차수가 1인 방정식입니다.

일반형:

`ax + b = 0` (`a ≠ 0`)

해 공식:

`x = -b / a`

파이썬 함수로 만들기:

```python
def solve_linear(a: float, b: float) -> float:
    if a == 0:
        raise ValueError("a는 0이 될 수 없습니다.")
    return -b / a

print(solve_linear(2, -6))   # 3.0  -> 2x - 6 = 0
```

## 5. 연립일차방정식(聯立一次方程式)

미지수가 2개 이상이고, 방정식이 여러 개 묶인 형태입니다.

예:

```text
2x + y = 5
x - y = 1
```

두 식을 동시에 만족하는 `x`, `y`를 찾는 것이 목표입니다.

### 5-1. 대입/소거로 직접 풀기

두 번째 식에서 `x = y + 1`  
첫 번째 식에 대입:

`2(y + 1) + y = 5`  
`3y = 3` → `y = 1`  
`x = 2`

### 5-2. 파이썬으로 계산(직접 공식 사용)

```python
def solve_2x2(a, b, c, d, e, f):
    """
    ax + by = c
    dx + ey = f
    """
    det = a * e - b * d
    if det == 0:
        raise ValueError("해가 없거나 무수히 많습니다.")
    x = (c * e - b * f) / det
    y = (a * f - c * d) / det
    return x, y

x, y = solve_2x2(2, 1, 5, 1, -1, 1)
print(x, y)  # 2.0 1.0
```

## 6. 행렬(行列)의 수학적 의미

행렬은 숫자를 직사각형 배열로 정리한 것입니다.

```text
[ 2  1 ]
[ 1 -1 ]
```

연립일차방정식을 행렬로 쓰면 계산 구조가 명확해집니다.

`A x = b`

- `A`: 계수 행렬
- `x`: 미지수 벡터
- `b`: 상수 벡터

위 예제를 행렬로 쓰면:

```text
[ 2  1 ] [x] = [5]
[ 1 -1 ] [y]   [1]
```

즉, 연립일차방정식은 **행렬 방정식**으로 표현할 수 있고,  
해를 구하는 과정은 선형대수 계산으로 연결됩니다.

## 7. 파이썬 실습: 리스트 기반 행렬 계산(기초)

외부 라이브러리 없이도 2×2는 직접 풀 수 있습니다.

```python
A = [[2, 1], [1, -1]]
b = [5, 1]

def solve_by_matrix_2x2(A, b):
    a, b1 = A[0]
    c, d = A[1]
    e, f = b
    det = a * d - b1 * c
    if det == 0:
        raise ValueError("역행렬이 없어 해를 구할 수 없습니다.")
    x = (e * d - b1 * f) / det
    y = (a * f - e * c) / det
    return x, y

print(solve_by_matrix_2x2(A, b))  # (2.0, 1.0)
```

## 8. 학습 체크포인트

- `**`는 거듭제곱 연산자다.
- 제곱근은 `math.sqrt()` 또는 `x ** 0.5`로 계산할 수 있다.
- 일차방정식 `ax+b=0`의 해는 `-b/a`다.
- 연립일차방정식은 여러 식을 동시에 만족하는 값을 찾는다.
- 연립식은 `A x = b` 행렬 형태로 표현할 수 있다.

## 9. 한눈에 요약

- **거듭제곱**: 같은 수를 여러 번 곱하는 연산
- **지수**: 몇 번 곱하는지 나타내는 수
- **제곱근**: 제곱했을 때 원래 수가 되는 값
- **등식**: 두 식이 같음을 나타내는 식
- **미지수**: 아직 모르는 값(문자)
- **해**: 방정식을 참으로 만드는 값
- **연립일차방정식**: 여러 일차방정식을 동시에 만족하는 해를 찾는 문제
- **행렬**: 연립방정식을 구조적으로 표현하고 계산하는 도구
