# 📈 일차함수, 그래프, 좌표평면 기초 — 초등학생도 이해하는 쉬운 설명

이 문서는 아래 개념을 **한자(漢字) 병기**와 함께 아주 쉽게 설명합니다.

- 일차함수(一次函數)
- 그래프(圖表)
- 좌표평면(座標平面)
- 좌표(座標)
- x축(軸), y축(軸)
- 기울기(기울기, 傾斜)
- 절편(切片)
- 증가량(增加量)

---

## 1. 좌표평면(座標平面)이 뭐예요?

좌표평면은 **점의 위치를 숫자로 나타내는 종이**라고 생각하면 쉬워요.

- 가로선: **x축(軸)**
- 세로선: **y축(軸)**
- 두 축이 만나는 가운데 점: **원점(原點) (0, 0)**

예를 들어 `(3, 2)`는
- x축으로 오른쪽 3칸
- y축으로 위쪽 2칸
간 위치예요.

---

## 2. 좌표(座標)란?

좌표는 점의 주소예요.  
보통 `(x, y)`처럼 씁니다.

- 첫 번째 수: x값(가로 위치)
- 두 번째 수: y값(세로 위치)

예:
- `(1, 4)`: 오른쪽 1, 위로 4
- `(-2, 3)`: 왼쪽 2, 위로 3

---

## 3. 일차함수(一次函數)란?

일차함수는 보통 이렇게 생겼어요.

```text
y = ax + b
```

- `a`: 기울기(傾斜)
- `b`: y절편(切片)

`x`가 1씩 변할 때 `y`가 **항상 같은 양**으로 변하면 일차함수예요.

예:

```text
y = 2x + 1
```

여기서는 `x`가 1 커질 때 `y`는 2씩 커져요.

---

## 4. 그래프(圖表)와 직선

일차함수를 좌표평면에 그리면 **직선**이 됩니다.

`y = 2x + 1`에 x값을 넣어보면:

| x | y = 2x + 1 | 점(좌표) |
|---|---|---|
| 0 | 1 | (0, 1) |
| 1 | 3 | (1, 3) |
| 2 | 5 | (2, 5) |
| 3 | 7 | (3, 7) |

이 점들을 찍어 선으로 연결하면 직선 그래프가 돼요.

---

## 5. 기울기(傾斜)와 증가량(增加量)

기울기는 "x가 얼마나 바뀔 때 y가 얼마나 바뀌는지"를 말해요.

```text
기울기 = y의 증가량 / x의 증가량
```

예를 들어 `(1, 3)`에서 `(3, 7)`로 갈 때:

- x의 증가량: `3 - 1 = 2`
- y의 증가량: `7 - 3 = 4`
- 기울기: `4 / 2 = 2`

그래서 `y = 2x + 1`의 기울기는 2예요.

---

## 6. 절편(切片)이 뭐예요?

### 6-1. y절편(切片)

`x = 0`일 때의 y값입니다.  
즉, **그래프가 y축과 만나는 점**이에요.

`y = 2x + 1`에서 `x=0`이면 `y=1`,  
그래서 y절편은 `1` (점으로는 `(0, 1)`).

### 6-2. x절편(切片)

`y = 0`일 때의 x값입니다.  
즉, **그래프가 x축과 만나는 점**이에요.

`y = 2x + 1`에서 `0 = 2x + 1`  
`x = -0.5`, 그래서 x절편은 `-0.5` (점으로는 `(-0.5, 0)`).

## 7. 파이썬 예시 1 — 표 만들기 (초급)

```python
def linear_value(a: float, b: float, x: float) -> float:
    return a * x + b

a = 2   # 기울기
b = 1   # y절편

print("x | y")
for x in range(0, 6):
    y = linear_value(a, b, x)
    print(f"{x} | {y}")
```

실행 결과 예:

```text
x | y
0 | 1
1 | 3
2 | 5
3 | 7
4 | 9
5 | 11
```

## 8. 파이썬 예시 2 — 증가량과 기울기 구하기

```python
def slope_from_points(x1: float, y1: float, x2: float, y2: float) -> float:
    dx = x2 - x1   # x의 증가량
    dy = y2 - y1   # y의 증가량
    if dx == 0:
        raise ValueError("x의 증가량이 0이면 기울기를 계산할 수 없어요.")
    return dy / dx

x1, y1 = 1, 3
x2, y2 = 3, 7

print("x 증가량:", x2 - x1)     # 2
print("y 증가량:", y2 - y1)     # 4
print("기울기:", slope_from_points(x1, y1, x2, y2))  # 2.0
```

## 9. 파이썬 예시 3 — matplotlib로 그래프 그리기

```python
import matplotlib.pyplot as plt

a = 2
b = 1
x_values = [0, 1, 2, 3, 4, 5]
y_values = [a * x + b for x in x_values]

plt.plot(x_values, y_values, marker="o", label="y = 2x + 1")
plt.axhline(0, color="black", linewidth=1)  # x축
plt.axvline(0, color="black", linewidth=1)  # y축
plt.title("일차함수 그래프")
plt.xlabel("x축")
plt.ylabel("y축")
plt.grid(True)
plt.legend()
plt.show()
```

## 10. 학습 체크포인트

- **좌표평면(座標平面)**: 점의 위치를 나타내는 평면
- **좌표(座標)**: 점의 주소 `(x, y)`
- **일차함수(一次函數)**: `y = ax + b` 꼴
- **기울기(傾斜)**: x 증가량 대비 y 증가량
- **증가량(增加量)**: "얼마나 늘었는지"를 나타낸 값
- **y절편(切片)**: x=0일 때 y값
- **x절편(切片)**: y=0일 때 x값
- 일차함수 그래프는 **직선**이다

## 11. 한눈에 요약

```text
y = ax + b
│   │    └─ y절편(切片): x=0일 때 y값
│   └────── 기울기(傾斜): x가 1 늘 때 y가 얼마나 늘지
└────────── x와 y의 관계를 나타내는 식(일차함수)
```
