# PEP 8 (Python Enhancement Proposal 8) 가이드

파이썬(Python)의 공식 코딩 스타일 가이드인 **PEP 8**에 대해 정리한 문서입니다.

---

## 1. PEP 8이란?
- **풀네임:** Python Enhancement Proposal 8 (파이썬 개선 제안 8호)
- **작성자:** 귀도 반 로섬(Guido van Rossum) 등을 포함한 파이썬 개발자들
- **목적:** 여러 사람이 코드를 작성하더라도 모두가 동일한 스타일로 작성하여 **코드의 가독성(Readability)을 높이고 유지보수를 쉽게 하기 위함**입니다.

---

## 2. 주요 핵심 규칙

실무에서 가장 자주 쓰이는 핵심 코딩 스타일 규칙은 다음과 같습니다.

### 📍 1. 들여쓰기 (Indentation)
- **공백(Space) 4칸**을 사용하는 것을 강력하게 권장합니다.
- 탭(Tab)과 공백을 섞어서 사용하면 안 됩니다.

### 📍 2. 줄 바꿈
- 한 줄의 길이는 **최대 79자**를 넘지 않도록 권장합니다.
- 긴 문장은 역슬래시(`\`) 대신 괄호 `( )`를 사용해 줄을 나누는 것이 좋습니다.

### 📍 3. 공백(Whitespace)과 관련된 규칙
- 괄호 바로 안쪽에는 공백을 넣지 않습니다.
  - **O:** `func(my_list[1], {other: 2})`
  - **X:** `func( my_list[ 1 ], { other: 2 } )`
- 대입 연산자(`=`) 앞뒤로 공백을 한 칸씩만 둡니다.
  - **O:** `x = 1`
  - **X:** `x  =  1` 또는 `x=1`

### 📍 4. 이름 짓기 (Naming Conventions)
- **변수 및 함수:** `snake_case` (모두 소문자, 단어 사이는 언더스코어 `_` 사용)
  - *예시:* `total_price`, `get_user_info()`
- **클래스:** `PascalCase` (첫 글자 대문자, 단어 사이 대문자)
  - *예시:* `UserProfile`, `DatabaseConnection`
- **상수:** `SCREAMING_SNAKE_CASE` (모두 대문자)
  - *예시:* `MAX_CONNECTIONS = 100`

---

## 3. PEP 8을 따라야 하는 이유
1. **가독성 향상:** 다른 사람이 작성한 코드라도 쉽게 읽고 이해할 수 있습니다.
2. **협업의 효율성:** 코드 스타일로 인한 불필요한 논쟁을 줄여줍니다.
3. **오류 예방:** 일관된 패턴을 유지하면 오타나 문법적 실수를 빠르게 발견할 수 있습니다.

> **💡 팁:** PEP 8 규칙을 모두 외우지 않아도, `flake8`, `black`, `autopep8` 같은 자동화 도구(Formatter)를 사용하여 코드를 검사하고 자동으로 수정할 수 있습니다.
