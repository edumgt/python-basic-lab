## 1. 미지수(未知數)란?

방정식에서 **값을 아직 모르는 문자**를 미지수라고 합니다.

가장 흔하게 `x`, `y`, `z` 같은 알파벳을 씁니다.

예:

```text
x + 3 = 7
```

여기서 `x`가 미지수이고, 이 식을 참으로 만드는 값(`x = 4`)이 **해(解)** 입니다.

---

## 2. 항(項), 계수(係數), 상수항(常數項)

다항식의 구성 요소를 이해하면 방정식을 훨씬 쉽게 읽을 수 있습니다.

### 2-1. 항(項)

- **항**: 덧셈·뺄셈 기호로 구분된 각각의 덩어리
- 예: `3x² - 5x + 2` 는 세 개의 항(`3x²`, `-5x`, `2`)으로 이루어짐

### 2-2. 계수(係數)

- **계수**: 미지수(문자)에 곱해진 수
- 예: `3x²`에서 계수는 **3**, `-5x`에서 계수는 **-5**

### 2-3. 상수항(常數項)

- **상수항**: 미지수가 없는 수만 있는 항
- 예: `3x² - 5x + 2`에서 상수항은 **2**

### 2-4. 차수(次數), 최고차수, 최고차항

- 각 항에서 미지수의 지수를 **차수**라고 합니다.
- 식 전체에서 가장 큰 차수를 **최고차수**라고 합니다.
- 최고차수를 가진 항을 **최고차항**이라고 합니다.
- 예: `3x² - 5x + 2`의 최고차수는 **2**, 최고차항은 **`3x²`**입니다.

| 항    | 종류         | 계수 또는 값 |
|-------|--------------|-------------|
| `3x²` | 이차항       | 3           |
| `-5x` | 일차항       | -5          |
| `2`   | 상수항       | 2           |

파이썬에서 확인해 보기:

```python
# 3x² - 5x + 2 에서 x = 4 일 때 식의 값 계산
a = 3   # 이차항 계수
b = -5  # 일차항 계수
c = 2   # 상수항

x = 4
result = a * x**2 + b * x + c
print(result)  # 30  (= 3*16 - 5*4 + 2)
```

## 3. 이차함수(二次函數)란?

**미지수의 최고차수가 2인 함수**를 이차함수라고 합니다.

### 3-1. 일반형

```text
y = ax² + bx + c  (a ≠ 0)
```

| 기호 | 의미              |
|------|-------------------|
| `a`  | 이차항의 계수     |
| `b`  | 일차항의 계수     |
| `c`  | 상수항            |
| `ax²` (`a ≠ 0`) | 최고차항 |

예:

- `y = x² + 2x + 1` → `a=1, b=2, c=1`, 최고차항: `x²`
- `y = -2x² + 4x - 3` → `a=-2, b=4, c=-3`, 최고차항: `-2x²`
- `y = 5x² - 7` → `a=5, b=0, c=-7`, 최고차항: `5x²`

### 3-2. 계수 빠르게 읽기

| 식 | 이차항 계수 `a` | 일차항 계수 `b` | 상수항 `c` | 최고차항 |
|---|---:|---:|---:|---|
| `y = 3x² - 5x + 2` | 3 | -5 | 2 | `3x²` |
| `y = x² + 4` | 1 | 0 | 4 | `x²` |
| `y = -x² + x - 8` | -1 | 1 | -8 | `-x²` |

---

## 4. 이차방정식(二次方程式)이란?

**미지수의 최고차수가 2**인 방정식입니다.

### 4-1. 일반형

```text
ax² + bx + c = 0  (a ≠ 0)
```

| 기호 | 의미              |
|------|-------------------|
| `a`  | 이차항의 계수     |
| `b`  | 일차항의 계수     |
| `c`  | 상수항            |
| `x`  | 미지수            |

> `a = 0` 이면 이차방정식이 아니라 일차방정식이 됩니다.

예:

- `x² - 5x + 6 = 0` → `a=1, b=-5, c=6`
- `2x² + 3x - 2 = 0` → `a=2, b=3, c=-2`
- `x² - 4 = 0` → `a=1, b=0, c=-4`

## 5. 판별식(判別式, Discriminant)

근의 공식에서 제곱근 안의 값 `b² - 4ac`를 **판별식 D** 라고 합니다.

```text
D = b² - 4ac
```

판별식의 값에 따라 근(해)의 개수가 결정됩니다.

| D의 값  | 근의 종류              |
|---------|------------------------|
| D > 0   | 서로 다른 실수 근 2개  |
| D = 0   | 중근(같은 실수 근 1개) |
| D < 0   | 실수 근 없음(허수 근)  |

파이썬으로 판별식 계산:

```python
def discriminant(a: float, b: float, c: float) -> float:
    return b**2 - 4 * a * c

print(discriminant(1, -5, 6))   # 1  → 실수 근 2개
print(discriminant(1, -2, 1))   # 0  → 중근
print(discriminant(1, 0, 1))    # -4 → 실수 근 없음
```

## 6. 근의 공식(根의 公式)

이차방정식 `ax² + bx + c = 0`의 해:

```text
x = ( -b ± √(b² - 4ac) ) / (2a)
```

- `±`는 `+`일 때와 `-`일 때 두 근을 뜻합니다.
- 중근이면 두 근이 같습니다: `x = -b / (2a)`

## 7. 파이썬 실습

### 7-1. 근의 공식 함수 구현

```python
import math

def solve_quadratic(
    a: float, b: float, c: float
) -> tuple[float, float] | tuple[float] | None:
    """
    ax² + bx + c = 0 의 실수 해를 반환합니다.
    실수 해가 없으면 None을 반환합니다.
    """
    if a == 0:
        raise ValueError("a는 0이 될 수 없습니다. (일차방정식을 사용하세요)")

    D = b**2 - 4 * a * c

    if D > 0:
        x1 = (-b + math.sqrt(D)) / (2 * a)
        x2 = (-b - math.sqrt(D)) / (2 * a)
        return x1, x2
    elif D == 0:
        x = -b / (2 * a)
        return (x,)          # 중근(근이 1개)
    else:
        return None           # 실수 근 없음


# 예제 1: x² - 5x + 6 = 0  →  근: 3, 2
print(solve_quadratic(1, -5, 6))   # (3.0, 2.0)

# 예제 2: x² - 2x + 1 = 0  →  중근: 1
print(solve_quadratic(1, -2, 1))   # (1.0,)

# 예제 3: x² + 1 = 0  →  실수 근 없음
print(solve_quadratic(1, 0, 1))    # None
```

### 7-2. 결과 출력을 더 친절하게 만들기

```python
def describe_roots(a: float, b: float, c: float) -> None:
    result = solve_quadratic(a, b, c)
    expr = f"{a}x² + {b}x + {c} = 0"

    if result is None:
        print(f"{expr}  →  실수 근 없음")
    elif len(result) == 1:
        print(f"{expr}  →  중근: x = {result[0]}")
    else:
        print(f"{expr}  →  두 근: x = {result[0]}, x = {result[1]}")

describe_roots(1, -5, 6)    # 1x² + -5x + 6 = 0  →  두 근: x = 3.0, x = 2.0
describe_roots(1, -2, 1)    # 1x² + -2x + 1 = 0  →  중근: x = 1.0
describe_roots(1, 0, 1)     # 1x² + 0x + 1 = 0   →  실수 근 없음
```

### 7-3. NumPy로 풀기

`numpy.roots`를 사용하면 계수 배열 `[a, b, c]`만 넘기면 됩니다.

```python
import numpy as np

# x² - 5x + 6 = 0
roots = np.roots([1, -5, 6])
print(roots)        # [3. 2.]

# x² - 2x + 1 = 0  (중근)
roots = np.roots([1, -2, 1])
print(roots)        # [1. 1.]

# x² + 1 = 0  (허수 근)
roots = np.roots([1, 0, 1])
print(roots)        # [0.+1.j  0.-1.j]  ← 복소수
```

## 8. 학습 체크포인트

- **미지수**: 방정식에서 값을 모르는 문자(보통 `x`, `y`)
- **계수**: 미지수에 곱해진 수 (`3x`에서 `3`)
- **상수항**: 미지수 없이 수만 있는 항 (`+ 2`, `- 7` 등)
- **최고차항**: 가장 큰 차수(지수)를 가진 항 (`3x² - 5x + 2`에서 `3x²`)
- **이차함수**: `y = ax² + bx + c` 꼴 (`a ≠ 0`)
- **이차방정식**: 최고차수가 2인 방정식 → `ax² + bx + c = 0`
- **판별식** `D = b² - 4ac`: D > 0이면 근 2개, D = 0이면 중근, D < 0이면 실수 근 없음
- **근의 공식**: `x = (-b ± √D) / 2a`
- `math.sqrt`로 판별식에서 제곱근을 계산할 수 있다
- `numpy.roots([a, b, c])`로 이차방정식의 모든 근(복소수 포함)을 구할 수 있다

## 9. 한눈에 요약

```text
y = 3x² - 5x + 2
│   │      │    │
│   │      │    └─ 상수항(c = 2)
│   │      └────── 일차항의 계수(b = -5)
│   └───────────── 이차항의 계수(a = 3)
└───────────────── 최고차항: 3x²
```

- `a ≠ 0`이어야 이차함수/이차방정식
- 판별식 D로 근의 개수 먼저 판단
- 근의 공식으로 정확한 해 계산
- 파이썬 `math.sqrt` 또는 `numpy.roots` 활용
