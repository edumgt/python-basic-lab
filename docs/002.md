# 파이썬 들여쓰기(Indentation) 가이드

파이썬 프로그래밍에서 가장 독특하고 중요한 특징인 **들여쓰기**에 대해 정리한 문서입니다.

---

## 1. 들여쓰기란?
파이썬에서 들여쓰기는 단순한 코드 정렬 이상의 의미를 갖습니다. 다른 언어들이 중괄호(`{ }`)를 사용하여 코드의 범위를 지정하는 것과 달리, 파이썬은 **들여쓰기를 통해 코드의 논리적 블록(Block)을 정의**합니다.

- **필수 문법:** 들여쓰기를 지키지 않으면 `IndentationError`가 발생하여 프로그램이 실행되지 않습니다.
- **코드 블록:** 들여쓰기 수준이 같은 문장들은 동일한 블록에 속한 것으로 간주됩니다.

---

## 2. 타 언어와의 비교

| 특징 | 다른 언어 (C, Java, JS 등) | 파이썬 (Python) |
| :--- | :--- | :--- |
| **블록 구분** | 중괄호 `{ }` 사용 | **들여쓰기** 사용 |
| **가독성** | 개발자마다 스타일이 다를 수 있음 | 강제된 규칙으로 인해 항상 일정함 |
| **종료 표시** | `;` 또는 `}`로 끝남 | 들여쓰기가 끝나는 지점이 블록의 끝 |

---

## 3. 코드 예시
파이썬에서는 콜론(`:`) 다음에 반드시 들여쓰기가 뒤따라야 합니다.

```python
def check_weather(temperature):
    if temperature > 25:
        print("날씨가 덥습니다.")     # if문에 속함
        print("에어컨을 켭니다.")     # if문에 속함
    else:
        print("날씨가 적당합니다.")   # else문에 속함
    
    print("검사가 완료되었습니다.")   # 함수(def)에만 속함
