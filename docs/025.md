# 📈 matplotlib 기초 — pyplot, plot, grid, show

파이썬에서 데이터를 시각화할 때 가장 많이 쓰는 라이브러리 **matplotlib**을 소개하고,  
핵심 함수인 `plot`, `grid`, `show`를 예시와 함께 정리한 문서입니다.

---

## 1. matplotlib 이란?

`matplotlib`은 **데이터를 그래프(그림)로 그려주는 파이썬 라이브러리**입니다.

- 이름 뜻: **mat** (MATLAB 스타일) + **plot** (그래프) + **lib** (library)
- 주로 **선 그래프, 막대 그래프, 산점도, 히스토그램** 등을 그릴 때 씁니다.
- 설치: `pip install matplotlib`

---

## 2. pyplot 이란?

`matplotlib.pyplot`은 matplotlib 안에 들어 있는 **서브 모듈(sub module)**입니다.

- `pyplot`은 **MATLAB 스타일의 그래프 그리기 명령 모음**입니다.
- 관례적으로 `import matplotlib.pyplot as plt` 형태로 짧게 불러옵니다.

### `pyplot` 영어 이름 풀이

| 단어 | 뜻 |
|---|---|
| `py` | Python |
| `plot` | 그래프를 그리다 |
| `pyplot` | 파이썬으로 그래프를 그리는 도구 모음 |

### 기본 import

```python
import matplotlib.pyplot as plt
```

`as plt`는 긴 이름 `matplotlib.pyplot`을 짧게 `plt`라고 부르겠다는 뜻입니다.

---

## 3. plot() — 선 그래프 그리기

`plot()`은 데이터를 **선(line) 또는 점(marker)으로 그래프**를 그립니다.

### 기본 사용법

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 30, 25]

plt.plot(x, y)
plt.show()
```

### 자주 쓰는 옵션

```python
plt.plot(
    x, y,
    color="blue",       # 선 색상
    linewidth=2,        # 선 두께
    linestyle="--",     # 선 스타일: '-', '--', ':', '-.'
    marker="o",         # 데이터 점 모양: 'o', 's', '^', 'x'
    label="매출",       # 범례 이름
)
```

| 파라미터 | 설명 | 예시 |
|---|---|---|
| `color` | 선 색깔 | `"red"`, `"blue"`, `"#ff6600"` |
| `linewidth` | 선 두께 | `1`, `2`, `3` |
| `linestyle` | 선 스타일 | `"-"` (실선), `"--"` (점선) |
| `marker` | 데이터 점 모양 | `"o"` (원), `"s"` (사각형), `"^"` (삼각형) |
| `label` | 범례에 표시할 이름 | `"매출"`, `"온도"` |

---

## 4. grid() — 격자선 추가

`grid()`는 그래프 배경에 **격자(grid) 선**을 추가해서 값을 읽기 쉽게 만듭니다.

### 기본 사용법

```python
plt.grid(True)   # 격자선 켜기
plt.grid(False)  # 격자선 끄기 (기본값)
```

### 자주 쓰는 옵션

```python
plt.grid(
    True,
    color="gray",       # 격자선 색상
    linewidth=0.5,      # 격자선 두께
    linestyle="--",     # 격자선 스타일
    alpha=0.7,          # 투명도 (0.0 ~ 1.0)
)
```

| 파라미터 | 설명 |
|---|---|
| `color` | 격자선 색상 |
| `linewidth` | 격자선 두께 |
| `linestyle` | 격자선 스타일 |
| `alpha` | 투명도 (1.0 = 불투명, 0.0 = 완전 투명) |

---

## 5. show() — 그래프 화면에 표시

`show()`는 지금까지 그린 그래프를 **화면에 띄워 보여주는** 함수입니다.

```python
plt.show()
```

- 주피터 노트북(Jupyter Notebook)에서는 `show()` 없이도 자동으로 출력됩니다.
- 일반 파이썬 스크립트(`.py` 파일)를 실행할 때는 반드시 `show()`를 호출해야 그래프가 나타납니다.
- `show()` 이후 그래프 객체는 초기화되므로, 여러 그래프를 저장할 때는 `show()` 전에 `savefig()`를 먼저 호출합니다.

---

## 6. 자주 함께 쓰는 함수

| 함수 | 설명 |
|---|---|
| `plt.title("제목")` | 그래프 제목 추가 |
| `plt.xlabel("x축 이름")` | x축 이름 추가 |
| `plt.ylabel("y축 이름")` | y축 이름 추가 |
| `plt.legend()` | 범례 표시 (label이 있을 때) |
| `plt.savefig("파일명.png")` | 그래프를 파일로 저장 |
| `plt.figure(figsize=(w, h))` | 그래프 크기 지정 (단위: 인치) |
| `plt.xlim(min, max)` | x축 범위 지정 |
| `plt.ylim(min, max)` | y축 범위 지정 |

## 7. 종합 예제

아래 예제는 `plot`, `grid`, `show`와 자주 쓰는 꾸미기 함수를 모두 사용하는 기본 패턴입니다.

```python
import matplotlib.pyplot as plt

# 데이터
months = [1, 2, 3, 4, 5, 6]
sales  = [120, 150, 130, 170, 160, 200]

# 그래프 크기 설정
plt.figure(figsize=(8, 4))

# 선 그래프 그리기
plt.plot(
    months, sales,
    color="steelblue",
    linewidth=2,
    marker="o",
    label="월별 매출",
)

# 제목과 축 이름
plt.title("월별 매출 추이")
plt.xlabel("월(Month)")
plt.ylabel("매출(만 원)")

# 격자선
plt.grid(True, color="gray", linewidth=0.5, linestyle="--", alpha=0.7)

# 범례
plt.legend()

# 화면에 표시
plt.show()
```

실행하면 1~6월 매출 데이터가 파란 선과 원 마커로 그려지고,  
배경에는 회색 점선 격자가 표시됩니다.

## 8. 여러 선 겹쳐 그리기

`plot()`을 여러 번 호출하면 같은 그래프 위에 여러 선을 그릴 수 있습니다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y1 = [10, 20, 15, 30, 25]
y2 = [5, 15, 10, 20, 18]

plt.figure(figsize=(8, 4))

plt.plot(x, y1, color="blue",  marker="o", label="A팀")
plt.plot(x, y2, color="orange", marker="s", label="B팀")

plt.title("팀별 점수 비교")
plt.xlabel("라운드")
plt.ylabel("점수")
plt.grid(True, linestyle="--", alpha=0.6)
plt.legend()
plt.show()
```

---

## 9. 그래프를 파일로 저장하기

`savefig()`를 사용하면 그래프를 PNG, PDF 등으로 저장할 수 있습니다.  
반드시 `show()` **전에** 호출해야 합니다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [10, 20, 15, 30, 25]

plt.plot(x, y, color="green", marker="^", label="데이터")
plt.title("저장 예제")
plt.grid(True)
plt.legend()

plt.savefig("output.png", dpi=150, bbox_inches="tight")  # 파일 저장
plt.show()                                                # 화면 출력
```

| 파라미터 | 설명 |
|---|---|
| `dpi` | 해상도 (dots per inch). 클수록 고화질. 기본값 100 |
| `bbox_inches` | `"tight"` 로 설정하면 여백을 자동으로 조정 |
