# Mypy 가이드

파이썬(Python)의 정적 타입 검사기인 **Mypy**에 대해 정리한 문서입니다.

---

## 1. Mypy란?
- **정의:** 파이썬을 위한 **정적 타입 검사기(Static Type Checker)**입니다.
- **목적:** 파이썬은 동적 타이핑 언어이므로 자료형(Type) 관련 오류를 실행 전에 발견하기 어렵지만, Mypy를 사용하면 코드를 실행하지 않고도 타입 오류를 사전에 검출할 수 있습니다.
- **기반:** 파이썬의 **타입 힌트(Type Hints)** 문법(`->`, `: int` 등)을 활용하여 코드를 분석합니다.

---

## 2. 주요 핵심 특징

- **실행 전 오류 탐지:** 런타임 이전에 오류를 확인하여 개발 단계에서 버그를 예방합니다.
- **점진적 타이핑(Gradual Typing):** 프로젝트 전체를 한 번에 수정할 필요 없이, 원하는 파일이나 함수에만 선택적으로 타입을 적용할 수 있습니다.
- **성능 영향 없음:** 타입 검사는 개발 중에 수행되므로, 실제 프로그램의 실행 속도(성능)에는 영향을 주지 않습니다.
