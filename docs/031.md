## 1. 경우의 수가 뭐예요?

**경우의 수**는 "어떤 일이 일어날 수 있는 모든 방법의 개수"예요.

예를 들어 옷을 고를 때

- 모자 2개
- 티셔츠 3개

가 있다면,

```text
전체 경우의 수 = 2 × 3 = 6
```

왜냐하면 모자 하나를 고를 때마다 티셔츠 3개를 모두 짝지을 수 있기 때문이에요.

---

## 2. 순서가 중요할까요?

경우의 수는 **순서가 중요한지**에 따라 달라져요.

### 2-1. 순서가 중요할 때

예: 5명 중에서 **반장 1명, 부반장 1명** 뽑기

- 반장과 부반장은 역할이 달라요.
- `철수, 영희`와 `영희, 철수`는 다른 경우예요.

이럴 때는 **순열**처럼 생각합니다.

```text
5 × 4 = 20
```

### 2-2. 순서가 중요하지 않을 때

예: 5명 중에서 **대표 2명** 뽑기

- 둘 다 같은 대표예요.
- `철수, 영희`와 `영희, 철수`는 같은 경우예요.

이럴 때는 **조합**처럼 생각합니다.

```text
5명 중 2명 뽑기 = 10
```

## 3. 확률이 뭐예요?

**확률**은 어떤 일이 일어날 가능성을 숫자로 나타낸 것입니다.

기본 공식은 아주 간단해요.

```text
확률 = 원하는 경우의 수 / 전체 경우의 수
```

예: 주사위 1개를 던질 때 짝수가 나올 확률

- 전체 경우의 수: `6` (`1, 2, 3, 4, 5, 6`)
- 원하는 경우의 수: `3` (`2, 4, 6`)

그래서

```text
3 / 6 = 1 / 2
```

즉, 짝수가 나올 확률은 `1/2`입니다.

## 4. 확률의 덧셈

두 사건 중 **하나라도 일어날 확률**을 구할 때 씁니다.

```text
P(A 또는 B) = P(A) + P(B) - P(A이면서 B)
```

왜 빼 줄까요?  
`A`와 `B`를 그냥 더하면 **겹치는 부분**을 두 번 세기 때문이에요.

### 예: 카드 1장을 뽑을 때

- A: 하트가 나올 확률 = `13/52`
- B: K가 나올 확률 = `4/52`
- A이면서 B: 하트 K = `1/52`

따라서

```text
P(A 또는 B) = 13/52 + 4/52 - 1/52
             = 16/52
             = 4/13
```

### 서로 겹치지 않으면?

서로 동시에 일어날 수 없는 사건은 **배반 사건**이라고 해요.

예: 주사위를 한 번 던져서

- `1이 나오는 사건`
- `6이 나오는 사건`

은 동시에 일어날 수 없어요.

이때는 겹치는 부분이 `0`이므로

```text
P(A 또는 B) = P(A) + P(B)
```

## 5. 확률의 곱셈

두 사건이 **차례대로 모두 일어날 확률**을 구할 때 씁니다.

```text
P(A 그리고 B) = P(A) × P(B|A)
```

여기서 `P(B|A)`는  
"A가 이미 일어났다고 할 때 B가 일어날 확률"입니다.

### 예: 빨간 공 3개, 파란 공 2개가 들어 있는 주머니

공을 **넣지 않고** 2번 뽑을 때,
두 번 모두 빨간 공일 확률은:

1. 첫 번째가 빨간 공일 확률 = `3/5`
2. 첫 번째가 빨간 공이었다면 남은 빨간 공은 `2개`, 전체는 `4개`
3. 두 번째도 빨간 공일 확률 = `2/4`

그래서

```text
3/5 × 2/4 = 6/20 = 3/10
```

## 6. 독립 사건이란?

한 사건이 다른 사건에 **영향을 주지 않으면** 독립이라고 합니다.

예:

- 동전 던지기
- 주사위 던지기

동전 결과는 주사위 결과에 영향을 주지 않아요.

이럴 때는

```text
P(A 그리고 B) = P(A) × P(B)
```

### 예: 동전이 앞면이고, 주사위가 6일 확률

- 앞면 확률 = `1/2`
- 6이 나올 확률 = `1/6`

```text
1/2 × 1/6 = 1/12
```

## 7. 파이썬 예시 1 — 경우의 수 구하기

```python
import math

students = 5

# 반장 1명, 부반장 1명: 순서 중요
ordered_cases = math.perm(students, 2)

# 대표 2명: 순서 중요하지 않음
unordered_cases = math.comb(students, 2)

print("순서가 중요한 경우:", ordered_cases)
print("순서가 중요하지 않은 경우:", unordered_cases)
```

실행 결과 예:

```text
순서가 중요한 경우: 20
순서가 중요하지 않은 경우: 10
```

## 8. 파이썬 예시 2 — 확률 기본 계산

```python
def probability(favorable: int, total: int) -> float:
    return favorable / total

even_probability = probability(3, 6)  # 주사위에서 짝수: 2, 4, 6
print("짝수가 나올 확률:", even_probability)
```

## 9. 파이썬 예시 3 — 확률의 덧셈

```python
def addition_rule(prob_a: float, prob_b: float, prob_intersection: float) -> float:
    return prob_a + prob_b - prob_intersection

prob_heart = 13 / 52
prob_king = 4 / 52
prob_heart_king = 1 / 52

result = addition_rule(prob_heart, prob_king, prob_heart_king)
print("하트 또는 K가 나올 확률:", result)
```

## 10. 파이썬 예시 4 — 확률의 곱셈

```python
def multiplication_rule(prob_a: float, prob_b_given_a: float) -> float:
    return prob_a * prob_b_given_a

first_red = 3 / 5
second_red_given_first_red = 2 / 4

result = multiplication_rule(first_red, second_red_given_first_red)
print("연속으로 빨간 공 2개가 나올 확률:", result)
```
