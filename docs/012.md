# 🐍 `match` 패턴 매칭 심화 가이드

Python 3.10+의 구조적 패턴 매칭(`match`) 심화 사용법을 정리한 문서입니다.

---

## 1. 기본 형태

```python
def check(value):
    match value:
        case 0:
            return "zero"
        case _:
            return "other"
```

---

## 2. 시퀀스 패턴

```python
def parse_point(p):
    match p:
        case (0, 0):
            return "origin"
        case (x, 0):
            return f"x-axis: {x}"
        case (0, y):
            return f"y-axis: {y}"
        case (x, y):
            return f"point({x}, {y})"
```

---

## 3. 매핑(딕셔너리) 패턴

```python
def route(event):
    match event:
        case {"type": "click", "x": x, "y": y}:
            return f"click at {x},{y}"
        case {"type": "keydown", "key": key}:
            return f"key: {key}"
        case _:
            return "unknown"
```

---

## 4. 가드(Guard) 조건

```python
def classify(x):
    match x:
        case int() if x > 0:
            return "positive int"
        case int():
            return "non-positive int"
        case _:
            return "not int"
```

---

## 5. 주의사항

- `case _`는 기본 분기이므로 보통 마지막에 둡니다.
- 패턴 변수 바인딩 규칙을 이해하지 못하면 의도치 않은 매칭이 발생할 수 있습니다.
- Python 3.10 이상에서만 지원됩니다.
