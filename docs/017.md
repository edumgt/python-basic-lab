# 🐍 생성자와 인스턴스 속성 (`__init__`)

객체 초기화와 인스턴스 상태 관리 방법을 정리한 문서입니다.

---

## 1. 생성자 `__init__`

객체가 생성될 때 자동 호출되어 초기 상태를 설정합니다.

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

s = Student("Kim", 95)
print(s.name, s.score)
```

---

## 2. 인스턴스 속성과 클래스 속성

```python
class Counter:
    total = 0  # 클래스 속성

    def __init__(self):
        Counter.total += 1
        self.id = Counter.total  # 인스턴스 속성
```

- 클래스 속성: 모든 인스턴스가 공유
- 인스턴스 속성: 객체마다 독립

---

## 3. 기본값과 유효성 체크

생성자에서 기본값/검증 로직을 넣으면 안전한 객체를 만들 수 있습니다.

```python
class Product:
    def __init__(self, name, price=0):
        if price < 0:
            raise ValueError("price must be >= 0")
        self.name = name
        self.price = price
```

---

## 4. 요약

- `__init__`는 객체의 초기 상태를 책임집니다.
- 상태 불변식(유효성 조건)을 생성자에서 강제하면 오류를 줄일 수 있습니다.
