# 🐍 상속과 메서드 오버라이딩

부모 클래스 기능을 재사용/확장하는 상속을 정리한 문서입니다.

---

## 1. 상속 기본

```python
class Animal:
    def speak(self):
        print("...")

class Cat(Animal):
    pass
```

`Cat`은 `Animal`의 메서드를 물려받습니다.

---

## 2. 오버라이딩

자식 클래스에서 부모 메서드를 재정의할 수 있습니다.

```python
class Dog(Animal):
    def speak(self):
        print("멍멍")
```

---

## 3. `super()` 활용

부모 구현을 유지하면서 자식 기능을 추가할 때 유용합니다.

```python
class Bird(Animal):
    def speak(self):
        super().speak()
        print("짹짹")
```

---

## 4. 요약

- 상속은 코드 재사용성을 높입니다.
- 오버라이딩/`super()`를 적절히 쓰면 유연한 확장이 가능합니다.
