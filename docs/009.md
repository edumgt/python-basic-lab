# 🐍 중첩 함수 (Nested Function) 가이드

함수 안에 함수를 정의하는 중첩 함수 개념을 정리한 문서입니다.

---

## 1. 중첩 함수란?

함수 내부에 다른 함수를 정의하는 방식입니다.

```python
def outer():
    def inner():
        print("inner called")
    inner()

outer()
```

---

## 2. 왜 사용할까?

1. **로직 캡슐화**: 바깥 함수에서만 쓰는 보조 함수를 감출 수 있습니다.
2. **스코프 제어**: 바깥 함수의 지역 변수에 접근할 수 있습니다.

```python
def greet(name):
    prefix = "Hello"

    def message():
        return f"{prefix}, {name}"

    return message()
```

---

## 3. 실무에서의 활용

- 입력 검증용 보조 함수
- 데코레이터 구현의 기본 구조
- 클로저 생성의 출발점

---

## 4. 요약

- 중첩 함수는 함수 내부 보조 로직을 구조적으로 정리할 때 유용합니다.
- 바깥 함수 스코프와 결합하면 클로저로 확장됩니다.
