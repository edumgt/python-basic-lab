# 📊 도수분포표, 스터지스 공식, 히스토그램 기초 — 초등학생도 이해하는 쉬운 설명

이 문서는 아래 개념을 **아주 쉽게** 설명하고, 파이썬으로 직접 확인해 봅니다.

- 변량(變量)
- 계급(階級)
- 도수(度數)
- 도수분포표(度數分布表)
- 스터지스 공식(Sturges' rule)
- 히스토그램(Histogram)

---

## 1. 변량(變量)이 뭐예요?

**변량**은 조사해서 얻은 숫자 하나하나를 말해요.

예를 들어 학생 12명의 키를 재면,

```text
130, 132, 133, 134, 135, 136, 137, 138, 140, 141, 142, 144
```

이 숫자 각각이 모두 변량이에요.

---

## 2. 계급(階級)과 도수(度數)

변량이 많으면 보기 어려우니까, 비슷한 값끼리 **구간**으로 묶어요.
그 구간이 **계급**입니다.

예:
- 130~134
- 135~139
- 140~144

각 계급에 데이터가 몇 개 들어있는지 세면,
그 개수가 **도수**예요.

---

## 3. 도수분포표(度數分布表)

계급과 도수를 표로 정리한 것이 **도수분포표**입니다.

| 계급 | 도수 |
|---|---:|
| 130~134 | 4 |
| 135~139 | 4 |
| 140~144 | 4 |

이 표를 보면 데이터가 어느 구간에 많은지 한눈에 볼 수 있어요.

---

## 4. 스터지스 공식(Sturges' rule)

계급을 몇 개로 나눌지 정할 때 자주 쓰는 공식입니다.

```text
k = 1 + 3.322 × log10(n)
```

- `n`: 데이터 개수
- `k`: 권장 계급 개수

보통 `k`는 정수로 올림해서 사용해요.

예를 들어 `n=30`이면:

```text
k = 1 + 3.322 × log10(30) ≈ 5.9
```

그래서 계급 개수를 약 **6개**로 잡을 수 있어요.

---

## 5. 히스토그램(Histogram)

히스토그램은 도수분포를 **막대그래프처럼** 보여주는 그림이에요.

- 가로축: 계급(구간)
- 세로축: 도수(개수)

막대가 높은 구간일수록 데이터가 많이 모여 있다는 뜻입니다.

---

## 6. 파이썬 예시 1 — 스터지스 공식으로 계급 개수 구하기

```python
import math

def sturges_bins(n: int) -> int:
    if n <= 1:
        return 1
    return math.ceil(1 + 3.322 * math.log10(n))

samples = [130, 132, 133, 134, 135, 136, 137, 138, 140, 141, 142, 144]
n = len(samples)
print("데이터 개수 n:", n)
print("추천 계급 개수 k:", sturges_bins(n))
```

## 7. 파이썬 예시 2 — 도수분포표 만들기(기본)

```python
from collections import Counter

scores = [
    52, 55, 56, 59, 60, 61, 63, 64, 66, 67,
    70, 71, 73, 75, 76, 78, 80, 82, 84, 88,
]

# 계급폭(구간 너비) 10점으로 설정
# 50~59, 60~69, 70~79, 80~89
class_width = 10
start = 50

class_labels = []
for lower in range(start, 90, class_width):
    upper = lower + class_width - 1
    class_labels.append((lower, upper))

freq = Counter()
for x in scores:
    idx = (x - start) // class_width
    lower, upper = class_labels[idx]
    freq[(lower, upper)] += 1

print("계급 | 도수")
for c in class_labels:
    print(f"{c[0]}~{c[1]} | {freq[c]}")
```

실행 결과 예:

```text
계급 | 도수
50~59 | 4
60~69 | 6
70~79 | 6
80~89 | 4
```

## 8. 파이썬 예시 3 — 히스토그램 그리기

```python
import matplotlib.pyplot as plt

scores = [
    52, 55, 56, 59, 60, 61, 63, 64, 66, 67,
    70, 71, 73, 75, 76, 78, 80, 82, 84, 88,
]

bins = [50, 60, 70, 80, 90]  # [50~59], [60~69], [70~79], [80~89]

plt.hist(scores, bins=bins, edgecolor="black")
plt.title("점수 히스토그램")
plt.xlabel("점수 구간(계급)")
plt.ylabel("도수(학생 수)")
plt.grid(axis="y", alpha=0.3)
plt.show()
```

## 9. 학습 체크포인트

- **변량**: 조사해서 얻은 숫자 하나하나
- **계급**: 변량을 묶은 구간
- **도수**: 각 계급에 들어 있는 개수
- **도수분포표**: 계급과 도수를 표로 정리한 것
- **스터지스 공식**: 데이터 개수로 적당한 계급 수를 정하는 공식
- **히스토그램**: 도수분포를 막대로 시각화한 그래프

---

## 10. 한눈에 요약

```text

→ 각 구간 도수 세기
→ 도수분포표 만들기
→ 히스토그램으로 시각화
```
