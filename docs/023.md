# 📊 편차, 분산, 표준편차

데이터가 평균을 기준으로 얼마나 퍼져 있는지 이해하기 위한 핵심 통계 개념을 정리한 문서입니다.

---

## 1. 편차란?

편차는 **각 데이터와 평균의 차이**입니다.

- 공식: `편차 = 각 값 - 평균`
- 의미: 특정 값이 평균보다 큰지, 작은지 바로 파악할 수 있습니다.

예를 들어 데이터가 `[70, 80, 90]`이면 평균은 `80`이고 편차는 `[-10, 0, 10]`입니다.

---

## 2. 분산이란?

편차를 그대로 더하면 항상 0에 가까워지기 쉬우므로, 편차를 제곱해서 평균낸 값이 **분산**입니다.

- 모집단 분산: `((각 편차의 제곱 합) / 데이터 개수)`
- 표본 분산: `((각 편차의 제곱 합) / (데이터 개수 - 1))`

분산이 클수록 데이터 흩어짐이 크고, 분산이 작을수록 평균 근처에 모여 있습니다.

---

## 3. 표준편차란?

표준편차는 **분산에 제곱근을 취한 값**입니다.

- 공식: `표준편차 = √분산`
- 장점: 원래 데이터와 같은 단위를 사용하므로 해석이 더 쉽습니다.

예를 들어 시험 점수의 분산은 숫자가 크게 느껴질 수 있지만, 표준편차는 다시 점수 단위로 돌아오므로 직관적입니다.

---

## 4. 왜 AI/데이터 실습에서 중요한가?

- 데이터가 평균 주변에 고르게 모여 있는지 확인할 수 있습니다.
- 이상치(outlier)가 있는지 빠르게 감지할 수 있습니다.
- 정규화, 표준화, z-score 같은 전처리 개념을 이해하는 기초가 됩니다.
- 모델 입력 데이터의 안정성과 스케일을 점검할 때 자주 사용합니다.

## 5. 자주 쓰는 통계 함수(NumPy)

실무에서는 `numpy`의 통계 함수를 함께 사용합니다.

```python
import numpy as np

arr = np.array([1, 2, 2, 3, 5, 5, 5])
```

### `average`

- 산술평균(또는 가중평균)을 구합니다.
- 예: `np.average(arr)` → `3.29`
- 가중평균 예: `np.average([70, 80, 90], weights=[1, 2, 1])`

### `median`

- 중앙값을 구합니다.
- 예: `np.median(arr)` → `3.0`

### `bincount`

- 0 이상의 정수 데이터에서 각 값의 빈도를 계산합니다.
- 예: `np.bincount(arr)` → `[0, 1, 2, 1, 0, 3]`
  - 인덱스 `i`의 값은 숫자 `i`가 등장한 횟수입니다.

### `argmax` / `argmin`

- 최댓값/최솟값의 **위치(인덱스)**를 반환합니다.
- 예: `np.argmax(arr)` → `4` (`5`가 처음 등장한 위치)
- 예: `np.argmin(arr)` → `0`

### `var` / `std`

- `var`: 분산, `std`: 표준편차를 계산합니다.
- 예: `np.var(arr)` → 모집단 분산
- 예: `np.std(arr)` → 모집단 표준편차
- 표본 기준으로 계산하려면 `ddof=1` 사용:
  - `np.var(arr, ddof=1)`
  - `np.std(arr, ddof=1)`

---

## 6. 간단 예제

데이터: `[10, 12, 14, 16, 18]`

1. 평균: `14`
2. 편차: `[-4, -2, 0, 2, 4]`
3. 편차 제곱: `[16, 4, 0, 4, 16]`
4. 모집단 분산: `(16 + 4 + 0 + 4 + 16) / 5 = 8`
5. 모집단 표준편차: `√8 ≈ 2.83`
