# 📊 편차(偏差), 분산(分散), 표준편차(標準偏差)

데이터가 평균(平均)을 기준으로 얼마나 퍼져 있는지 아주 쉽게 이해하기 위한 문서입니다.  
처음 배우는 학생도 읽을 수 있도록 쉬운 말, 풀어쓴 영어 이름, 자주 쓰는 NumPy 함수 설명을 함께 넣었습니다.

---

## 1. 먼저 단어부터 쉽게 보기

- **편차(偏差)**: 평균에서 얼마나 떨어졌는지
- **분산(分散)**: 데이터가 얼마나 흩어져 있는지
- **표준편차(標準偏差)**: 분산을 다시 이해하기 쉬운 크기로 바꾼 값
- **평균(平均)**: 값을 모두 더해서 개수로 나눈 값

예를 들어 시험 점수가 `[70, 80, 90]`이면 평균은 `80`입니다.

---

## 2. 편차(偏差)란?

편차는 **각 데이터와 평균의 차이**입니다.

- 공식: `편차 = 각 값 - 평균`
- 뜻: 어떤 값이 평균보다 큰지 작은지 바로 알 수 있습니다.

예:

- `70 - 80 = -10`
- `80 - 80 = 0`
- `90 - 80 = 10`

그래서 편차는 `[-10, 0, 10]`입니다.

쉽게 말하면, **평균에서 왼쪽으로 얼마나 갔는지, 오른쪽으로 얼마나 갔는지**를 적은 숫자입니다.

---

## 3. 분산(分散)이란?

편차를 그냥 더하면 `-10 + 0 + 10 = 0`처럼 서로 지워질 수 있습니다.  
그래서 **편차를 제곱해서 모두 더한 뒤 평균**을 내면 데이터가 얼마나 퍼졌는지 더 잘 알 수 있습니다.  
이 값이 **분산(分散)**입니다.

- 모집단 분산: `((각 편차의 제곱 합) / 데이터 개수)`
- 표본 분산: `((각 편차의 제곱 합) / (데이터 개수 - 1))`

분산이 크면 데이터가 넓게 퍼져 있고, 분산이 작으면 평균 근처에 모여 있습니다.

---

## 4. 표준편차(標準偏差)란?

표준편차는 **분산에 제곱근을 취한 값**입니다.

- 공식: `표준편차 = √분산`
- 좋은 점: 원래 데이터와 비슷한 크기로 돌아와서 읽기 쉽습니다.

예를 들어 시험 점수의 분산은 숫자가 크게 느껴질 수 있지만,  
표준편차는 다시 점수 느낌으로 볼 수 있어서 더 직관적입니다.

---

## 5. 왜 중요할까?

- 점수나 키가 평균 주변에 모였는지 알 수 있습니다.
- 유난히 너무 크거나 작은 값, 즉 이상치(outlier)를 찾는 데 도움 됩니다.
- AI, 데이터 분석에서 데이터를 정리하고 비교할 때 자주 씁니다.

## 6. NumPy를 쓰기 전에: `import`와 영어 이름 이해하기

실무에서는 `numpy`라는 라이브러리(library)를 자주 씁니다.

### `import` 뜻

`import`는 영어로 **"가져오다"**, **"불러오다"**라는 뜻입니다.  
파이썬에서는 **다른 사람이 미리 만들어 둔 도구를 내 프로그램으로 가져오는 명령**입니다.

### `library` 뜻

프로그래밍의 **라이브러리(library)**는 책이 모여 있는 도서관처럼,  
**도구와 기능이 많이 모여 있는 꾸러미**라고 생각하면 쉽습니다.

### `NumPy` 뜻

`NumPy`는 **Numerical Python**의 줄임말입니다.

- `Numerical`: 숫자를 다루는
- `Python`: 파이썬

즉, **숫자 계산을 잘하게 도와주는 파이썬 도구 모음**입니다.

### `np` 뜻

```python
import numpy as np
```

여기서 `as np`는 **긴 이름 `numpy`를 짧게 `np`라고 부르자**는 뜻입니다.  
이런 짧은 이름을 **별명(alias)**이라고 합니다.

### `arr` 뜻

```python
arr = np.array([1, 2, 2, 3, 5, 5, 5])
```

`arr`는 보통 **array(배열)**의 줄임말입니다.  
즉, 숫자 여러 개를 담아 둔 묶음이라고 생각하면 됩니다.

## 7. 자주 보는 NumPy 함수와 full name

```python
import numpy as np

arr = np.array([1, 2, 2, 3, 5, 5, 5])
```

### `array`

- 뜻: 여러 값을 한 줄로 담은 **배열(array)**
- 예: `np.array([1, 2, 3])`

### `arange`

사용자가 `arrange`로 잘못 기억하기 쉽지만,  
NumPy의 실제 함수 이름은 **`arange`**입니다.

- 이름 기억법: **array + range → arange**로 줄어든 말이라고 생각하면 쉽습니다.
- 뜻: **array**와 **range**가 합쳐진 이름으로 이해하면 쉽습니다.
- 역할: 일정한 간격으로 숫자를 차례대로 만듭니다.
- 예: `np.arange(1, 6)` → `[1, 2, 3, 4, 5]`
- 예: `np.arange(0, 10, 2)` → `[0, 2, 4, 6, 8]`

### `average`

- full meaning: **average** = 평균(平均)
- 역할: 평균을 구합니다.
- 예: `np.average(arr)` → `3.29`
- 가중평균 예: `np.average([70, 80, 90], weights=[1, 2, 1])` → `80.0`

### `median`

- full meaning: **median** = 중앙값
- 역할: 가운데 값을 구합니다.
- 예: `np.median(arr)` → `3.0`

### `bincount`

- full meaning: **bin count**
- 역할: 각 숫자가 몇 번 나왔는지 셉니다.
- 예: `np.bincount(arr)` → `[0, 1, 2, 1, 0, 3]`
  - 인덱스 `1`의 값 `1`은 숫자 `1`이 1번 나왔다는 뜻입니다.
  - 인덱스 `5`의 값 `3`은 숫자 `5`가 3번 나왔다는 뜻입니다.

### `argmax` / `argmin`

- `argmax` = **argument of maximum**
- `argmin` = **argument of minimum**
- 역할: 가장 큰 값, 가장 작은 값이 있는 **위치(인덱스)**를 찾습니다.
- 예: `np.argmax(arr)` → `4`
- 예: `np.argmin(arr)` → `0`

### `var` / `std`

- `var` = **variance** = 분산(分散)
- `std` = **standard deviation** = 표준편차(標準偏差)
- 예: `np.var(arr)` → 모집단 분산
- 예: `np.std(arr)` → 모집단 표준편차
- 표본 기준으로 계산하려면 `ddof=1`을 사용합니다.
  - `np.var(arr, ddof=1)`
  - `np.std(arr, ddof=1)`

## 8. 간단 예제

데이터: `[10, 12, 14, 16, 18]`

1. 평균(平均): `14`
2. 편차(偏差): `[-4, -2, 0, 2, 4]`
3. 편차 제곱: `[16, 4, 0, 4, 16]`
4. 모집단 분산(分散): `(16 + 4 + 0 + 4 + 16) / 5 = 8`
5. 모집단 표준편차(標準偏差): `√8 ≈ 2.83`

즉, 이 데이터는 평균 `14`를 중심으로 어느 정도 퍼져 있고,  
그 퍼진 정도를 숫자로 보여 주는 것이 분산과 표준편차입니다.
